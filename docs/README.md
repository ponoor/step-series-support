# STEP Series documentation (source)

This folder is the source of the STEP400 / STEP800 documentation site:

- 日本語: https://ponoor.com/docs/step-series/
- English: https://ponoor.com/docs/step-series/en/

To read the documentation, use the site above. This file is for people who change the pages. Questions go to the [forum](https://github.com/ponoor/step-series-support/discussions). For the whole repository (other folders, building, checks), see the [top README](../README.md).

## Layout

```
docs/
├── ja/                 Japanese pages (the top of the site)
├── en/                 English pages (the site's en/), same file names as ja/
│   ├── index.md
│   ├── getting-started/   connections/   guides/
│   ├── reference/         OSC reference (mostly generated, see below)
│   ├── hardware/          maintenance/   step100-200/
├── assets/
│   ├── images/         images used by the pages
│   ├── files/          PDFs (schematics, dimensions)
│   ├── extra.css       site styles (brand colours, fonts; see the variables at the top)
│   └── toc-commands.js right-hand table of contents of the OSC reference pages
├── llms.txt, llms-full.txt   generated by tools/generate.py (do not edit)
├── _redirects_map.md   old WordPress URL → new page (used by tools/gen_htaccess.py; not published)
└── README.md           this file (not published)
```

The navigation (page order and section names) is in [`mkdocs.yml`](../mkdocs.yml) (`nav`). Section names are written in English there; the Japanese names are under `nav_translations`.

## Generated and hand-written parts

Most of `reference/` is generated from [`spec/osc-commands.yaml`](../spec/osc-commands.yaml) by `tools/generate.py`. Generated text sits between markers:

```markdown
<!-- generated:begin osc /run -->
...
<!-- generated:end osc /run -->
```

- **Do not edit between the markers**: the next `generate.py` run overwrites it, and the checks fail. Change `spec/osc-commands.yaml` (the `en` and `ja` text together) or `tools/generate.py` instead, then run `python tools/generate.py --defaults both --coverage`.
- Text outside the markers is hand-written and can be edited as usual.

## Rules for editing pages

- **Both languages.** A page exists in `ja/` and `en/` with the same path. Change both in the same pull request (if you can only write one language, say so in the pull request).
- **Links are relative** to the `.md` file (`../guides/homing-and-position.md#…`), never `https://ponoor.com/…` for pages of this site. `mkdocs build --strict` stops on a broken link or a missing heading anchor.
- **Images and PDFs** go in `assets/images/` and `assets/files/`, linked with relative paths. Do not link to `wp-content` (a test checks this).
- **A new page**: add it to `ja/` and `en/`, and to `nav` in `mkdocs.yml`.
- **Japanese terms** follow [`spec/glossary_ja.yaml`](../spec/glossary_ja.yaml); `python tools/validate_spec.py --ja` checks the pages. Main rules: katakana words without the final long vowel (モータ, センサ, ユーザ), no space between Japanese and alphanumerics, STEP400 / STEP800 are called ボード.
- **English**: plain and short. Suggestions to make the English clearer are welcome.

## Preview

From the repository root:

```sh
pip install -r requirements-docs.txt -r tools/requirements.txt
python tools/generate.py --defaults both --coverage
mkdocs serve
```

Before a pull request, run the checks listed in the [top README](../README.md#checks).
