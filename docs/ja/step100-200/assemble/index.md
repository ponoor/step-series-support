# 組み立て

STEP100またはSTEP200を、次の順に組み立てます。ボードを重ねる前にX-NUCLEOボードを改造する必要がありますので、まず使う製品のページをご覧ください。

1. X-NUCLEOボードの準備: [STEP100（X-NUCLEO-IHM03A1）](step100.md)または[STEP200（X-NUCLEO-IHM02A1）](step200.md)。Ethernetシールドとピンが重ならないように、ピンを切ったり、抵抗を移したりします。
2. [接続](connections.md): Arduino、Ethernetシールド、X-NUCLEOボードを重ね、電源とモータをつなぎます。

ファームウェアを書き込む（[スケッチの書き込み](../upload-the-sketch.md)）まで、電源は入れないでください。
