# ブラウザ設定ツール

ブラウザ設定ツールは、USBでボードの設定を読み、編集して、ボードのmicroSDカードに保存します。カードを抜く必要はありません。Webブラウザで動くので、インストールは要りません。

ツールはここにあります: <https://ponoor.com/tools/step-config/>

ツールが使えるのは、ファームウェアv2.1.0以降です。ツールは、ファームウェアv2.2.0で確認しました。ツールのバージョンは、ファームウェアのバージョンとは別です。ツールの名前の横に、`v2.1.0 · checked with firmware v2.2.0`と表示されます。

設定の意味と、変更が効くときについては、[設定の仕組み](how-settings-work.md)をご覧ください。

## 必要なもの {#requirements}

- Google ChromeまたはMicrosoft Edge（Web Serial APIが必要です）。FirefoxとSafariでは、シリアルの機能は使えず、**Load JSON**と**Download JSON**だけが使えます。
- パソコンとボードをつなぐUSBケーブル（充電専用ではなく、データ通信ができるもの）。
- ボードのファームウェアがv2.1.0以降であること。
- カードに保存するときは、ボードに入れたmicroSDカード。[microSDカードでの設定](microsd-card.md)をご覧ください。

## ボードとの接続 {#connecting}

1. ボードの電源を入れ、USBケーブルをパソコンにつなぎます（USBだけでは、制御回路にしか電源が入りません）。
2. ChromeまたはEdgeでツールを開きます。
3. **Connect**をクリックします。
4. ブラウザのダイアログで、ボードのシリアルポートを選びます。
5. ツールがボードの設定を読んで表示します。**Read from Board**で、もう一度読めます。

接続にカードは要りません。保存するときに必要です。

## 設定の読み込みと編集 {#editing}

設定は、開け閉めできるパネルに並んでいます。**Board Info**、**Network**、**Alarm & Report**、**Driver Settings**、**Speed Profile**、**Voltage Mode**、**Current Mode (PowerSTEP01)**、**Servo Mode**です。モータごとの設定は、モータ1つにつき1列で並びます。**Copy Motor 1 → All**は、モータ1の値を、パネルの中のほかのモータにコピーします。

- ツールは、読み込んだ設定にある項目だけを表示します。**Current Mode**のパネルはSTEP400（とSTEP100）、LIMITスイッチの項目はSTEP400、ブレーキの項目はブレーキ出力のあるボード（STEP400とSTEP800）に出ます。
- **Board Info**で編集できるのは、設定名（32文字まで）だけです。製品名と設定のバージョンは読み取り専用です。ファームウェアのバージョンは、ボードのバージョンです。設定をファイルから読んだときは、モータの数（Axes）も選べます。ボードから読んだときは、固定です。
- 過電流とストールの閾値とTVALは、電流を併記して表示します。刻みはSTEP400とSTEP800で異なります（[アラームと保護](../guides/alarms-and-protection.md#thresholds)をご覧ください）。TVALは64（約5A）まで選べます。
- スルーレートは、STEP400では6段階、STEP800では3段階です。
- MACアドレスは10進数で表示します。**Show Hex**で、16進数の表示に切り替えられます。
- ツールは、空の値、数値でない値、範囲外の値を受け付けず、保存とダウンロードを拒否します。設定名に`{`か`}`があるときと、設定が大きすぎて送れないとき（4095バイトを超えるとき）も拒否します。最後の場合は、**Download JSON**で保存して、ファイルをカードにコピーしてください。

ツールで値を変えても、動いているボードは変わりません。値は、保存するときに適用されます。保存したあとも、IPアドレス、ポート、MACアドレス、ボードがドライバに書く設定は、再起動しないと効きません。[変更が効くとき](how-settings-work.md#when)をご覧ください。

## カードへの保存 {#saving}

### Save to SD {#save-to-sd}

**Save to SD**は、値をボードに送ります。ボードは、値をメモリに適用して、カードに書きます（[`/saveConfig`](../reference/system-settings.md#saveconfig)と同じ処理です）。**保存の間、ボードは約0.1sから0.7sの間、処理を止めます。先にモータを止めてください。** ツールは、ボタンの横にこの注意を表示します。

保存に失敗したときは、ツールが、ボードの返信を、考えられる原因とともに表示します。`No SD card`と`SD open failed`の原因は、[エラー](microsd-card.md#errors)にあります。

### ファイル名 {#file-name}

**Save to SD**の左のテキスト欄が、ボードが保存するファイルの名前です。**Read from Board**のあとは、ボードが知らせるファイル名（起動時に読んだファイル、または`/config.txt`）になります。**Load JSON**を使うと、読み込んだファイルの名前になります。

- 名前は、`/`で始まり、`.json`か`.txt`で終わり、63バイトまでにする必要があります。この規則に合わないと、欄が赤くなり、ツールは保存を拒否します。
- 起動時にボードが読むのは、`/config.txt`と、ルートフォルダの最初の`*.json`だけです。名前がサブフォルダの中、`.`で始まる、または`/config.txt`以外の`.txt`のときは、欄が黄色になり、保存する前に「Save anyway?」と尋ねます。ファイルは保存されますが、次の起動でボードはそれを読みません。[`F<path>`で決めた名前](microsd-card.md#f-path)をご覧ください。

決めた名前は、ボードを再起動するまで使われます。再起動すると、ボードは、起動時に読んだファイルに保存します。

### 保存のあと {#after-saving}

保存に成功すると、ツールは、ボードをいま再起動するかどうかを尋ねます。再起動を選ぶと、ボードが再起動し、ツールは接続を閉じます。**Connect**をもう一度クリックしてください。あとから**Reboot**で再起動することもできます。保存していない変更は消えます。

### Download JSON {#download}

**Download JSON**は、ツールにある設定を、`.json`ファイルとしてパソコンに保存します。ファイル名は、ファイル名の欄の名前から、先頭の`/`を除いたものです。バックアップや、カードにコピーするファイルの用意に使います。

## ボードなしでの作業 {#offline}

ボードがなくても、設定ファイルを用意できます。

1. 接続せずに、ChromeまたはEdgeでツールを開きます。
2. **Load JSON**をクリックして、設定ファイル（`config.txt`か`.json`）を選びます。
3. 値を編集します。
4. **Download JSON**をクリックします。

ファイルをカードにコピーするか、あとでボードをつないで、**Load JSON**でファイルを読み込み、**Save to SD**をクリックします。ファイルの場合、ツールは製品を`information.targetProduct`（またはモータの数）から決めます。ファイルが、つないだボードと同じ製品のものかどうかは、ツールは確認しません。ご自身で確認してください。

## 状態の表示 {#status}

**Start Status**をクリックすると、**Real-time Status**に、ボードとモータの状態が表示されます。クリックしてから、ツールは1秒ごとにボードに問い合わせます（自動では始まりません）。製品、IPアドレス、Ethernetのリンク、カード、設定、そして、モータごとに、位置、速度、BUSYかどうか、無励磁かどうか、回転方向、モータの状態、過熱の状態、UVLO、HOMEスイッチ、原点復帰の状態、サーボモードが表示されます。

- **OCD**と**Stall**は"not reported"と表示されます。USBシリアルの状態の出力には、これらが含まれないためです。OSCメッセージの`/overCurrent`と`/stall`を使ってください（[アラームと保護](../guides/alarms-and-protection.md#timing)）。
- LIMITスイッチの状態は表示されません。

## ファームウェアのバージョン {#versions}

ツールは、ボードを読んだあとに、ファームウェアがv2.1.0より古いとき、またはツールが確認したバージョンより新しいときは、注意を表示します。

- `This tool requires firmware v2.1.0 or later (this board: vX.Y.Z).`
- `This tool was checked with firmware v2.2.0. Some settings of firmware vX.Y.Z may not be shown.`

ツールが比べるのはメジャーとマイナーの番号だけなので、v2.2.1のようなパッチのバージョンでは注意は出ません。注意は、バナーに数秒間表示されます。これらの注意で、ツールが止まることはありません。

## トラブルシューティング {#troubleshooting}

### Connectボタンが押せない {#no-connect-button}

お使いのブラウザがWeb Serial APIに対応していません。Google ChromeまたはMicrosoft Edgeを使ってください。

### シリアルポートの一覧にボードが出ない {#port-not-listed}

- USBケーブルが、充電専用ではなく、データ通信ができるものか確認してください。
- 別のUSBポートを試してください。
- Windowsでは、デバイスマネージャーにボードが出ているか確認してください。
- macOSとLinuxでは、ボードは`/dev/tty.usbmodem*`や`/dev/ttyACM*`のようなデバイスです。

### ツールに思っていない値が表示される {#unexpected-values}

ツールが読むのは、ボードの動いている設定です。起動したあとにOSCコマンドでボードを変えていると、カードのファイルとは異なることがあります。動いている値を残すには、**Save to SD**を使ってください。

### 保存しても設定が変わらない {#not-applied}

IPアドレス、ポート、MACアドレス、ボードがドライバに書く設定は、再起動が必要です。ボードを再起動してください。[変更が効くとき](how-settings-work.md#when)をご覧ください。

### 保存に失敗する {#save-fails}

- ボードにmicroSDカードが入っていること、ボードが起動したときにも入っていたことを確認してください。
- カードがFAT16またはFAT32であること（exFATは使えません）、書き込み禁止になっていないことを確認してください。
- `No SD card`と`SD open failed`のメッセージについては、[エラー](microsd-card.md#errors)をご覧ください。

## 古いファームウェア {#legacy}

v2.1.0より前のファームウェアには、製品ごとの設定ツールを使います。[古いファームウェア](microsd-card.md#legacy)をご覧ください。
