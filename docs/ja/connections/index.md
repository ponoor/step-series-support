# 接続と設定

最初の動作の前に行うこと、つまり電源、モータ、スイッチ、ネットワークの配線と、ボードの設定をまとめたセクションです。手順と配線を扱います。機能の仕組みは[機能ガイド](../guides/index.md)で説明しています。

## ページの一覧 {#pages}

- [電源とモータ](power-supply-and-motor.md): 電源の入力、モータの端子、電源とモータの選び方です。
- [センサとスイッチ](sensors-and-switches.md): HOME端子とLIMIT端子、ピン配置、スイッチとセンサの配線です。
- [ネットワークとDIPスイッチ](network-and-dip-switch.md): ID、ネットワークの初期設定、MACアドレスです。
- [電磁ブレーキの接続](electromagnetic-brake-wiring.md): STEP800のブレーキ出力と、STEP400用のEMB-STEP400の配線です。
- [設定の仕組み](how-settings-work.md): 設定がどこにあり、いつ効き、どこに保存されるかです。
- [microSDカードでの設定](microsd-card.md): カードの準備と設定ファイルです。
- [ブラウザ設定ツール](browser-config-tool.md): USBで設定を読み、編集し、保存します。
- [設定項目一覧](configuration-items.md): 設定ファイルのすべての項目と、初期値、範囲です。
- [モータ別のパラメータ例](example-parameters.md): いくつかのモータの設定ファイルです。
